# Конструктор КП ЮЗМ 2.7.7

[Скачать установочный ZIP](https://github.com/Keiner-kaka/BITRIXXX/raw/refs/heads/release/v2.7.7/dist/yuzm-kp-bitrix-2.7.7.zip)

Отдельная версия на базе 2.7.6. Единственное функциональное изменение — ввод цены произвольных позиций через цену за килограмм и вес.

Для произвольных строк, добавленных кнопкой «Добавить поле», вместо ввода базовой цены отображаются два компактных поля в одной строке: «Цена за кг.» и «Вес,кг.». Для расчёта обоих значений требуется заполнение. Базовая цена = вес в кг × цена за кг. Далее без изменений применяется прежняя формула: (базовая цена + включённые метизы) × К1 × К2 × К3, затем количество и выбранное округление. Произведение рассчитывается с прежней десятичной арифметикой без дополнительного округления.

В JSON произвольной строки отдельно записываются `pricePerKg` и `weightKg`; вычисленная базовая цена в JSON версии Диска не сохраняется как входной параметр. Загрузка восстанавливает эти значения в отдельные поля. Черновик браузера сохраняет оба введённых значения. У каталожных строк сохранены прежний ввод базовой цены и отсутствие требования веса.

Старые произвольные строки, в которых известна только базовая цена, не преобразуются автоматически: цену за кг и вес необходимо указать явно. Значения не угадываются. Старый JSON произвольной строки без этих двух параметров не проходит проверку расчёта при восстановлении; текущие поля при ошибке не заменяются.

Общие настройки администратора, несколько товаров доставки, подтверждение загрузки, привязка JSON к документу, перенос строк и генерация документов сохранены.

Для обновления замените файлы приложения содержимым ZIP и нажмите Ctrl+F5. `index.html` расположен в корне архива.

```sh
node --test versions/2.7.7/tests/*.test.mjs
python versions/2.7.7/tests/browser-weight.py
python versions/2.7.7/tests/browser-load.py
```

Проверены расчёт произведения без промежуточного округления, неизменность коэффициентов/метизов/доставки, оба режима округления, обязательность двух полей, каталожные позиции без веса и отдельные значения в JSON. В Chromium проверены расположение полей рядом при ширине окна 1440 и 400 пикселей, расчёт при вводе, сохранение черновика после перезагрузки и загрузка JSON без записи в CRM и генерации. Выполнены проверки синтаксиса и соответствия ZIP исходникам. Проверки API выполнялись с имитацией; рабочий портал не проверялся.
