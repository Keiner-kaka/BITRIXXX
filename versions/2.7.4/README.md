# Конструктор КП ЮЗМ 2.7.4

Версия на базе 2.7.3: загрузка расчёта из JSON с Битрикс Диска и связь сохранённого расчёта с документом.

[Скачать установочный ZIP](https://github.com/Keiner-kaka/BITRIXXX/raw/refs/heads/release/v2.7.4/dist/yuzm-kp-bitrix-2.7.4.zip)

## Загрузка

В истории документов кнопка «Загрузить» находится слева от «Скачать DOCX». Она открывает диалог с предупреждением о замене текущего расчёта. Сначала читается только список файлов папки; содержимое JSON скачивается после нажатия «Подтвердить загрузку и заменить расчёт». Отмена оставляет текущие данные без изменений.

Связанные JSON выбираются по ID документа в имени файла. Перед применением дополнительно проверяются ID документа и сделки внутри JSON. Восстанавливаются наименования, цены, количество, К1/К2/К3, покрытие, метизы, срок исполнения, компания, валюта, округление и правило товара доставки. Остальные поля конструктора, которых нет в JSON версии 2.7.3, сохраняют текущие значения.

Загрузка не переносит строки в CRM, не запускает генератор и не создаёт новую JSON-версию. Сначала проверяется весь файл и расчёт по нему; при ошибке текущие поля не заменяются. Загрузка ограничена настроенной папкой Диска. Нужны права чтения файлов и доступность DOWNLOAD_URL через CORS портала.

## Связь с документом

При генерации, как в 2.7.3, сначала сохраняется отдельный JSON параметров. После получения ID документа тот же файл обновляется методом `disk.file.uploadVersion`: в JSON добавляется `documentId`; затем `disk.file.rename` добавляет к имени `-document-ID.json`. UUID расчётной версии и ID файла остаются прежними. Это требует права редактирования файла на Диске. При ошибке привязки интерфейс сообщает, что документ создан, JSON сохранён, но связь не подтверждена; повторная генерация в том же предпросмотре заблокирована.

JSON переноса строк без генерации документа остаётся без documentId. Для старых документов без связанного файла доступен ручной выбор прежнего JSON этой сделки без привязки. Диалог явно сообщает, что соответствие документу не подтверждено. JSON, связанный с другим документом, не применяется.

Предпросмотр по-прежнему не сохраняет версий. Правила расчёта и подтверждения переноса не изменены.

## Установка и проверка

Замените файлы приложения содержимым ZIP и обновите страницу с очисткой кеша. В настройках должен быть указан ID папки Битрикс Диска. Файлы приложения находятся непосредственно в корне ZIP.

```sh
node --test versions/2.7.4/tests/*.test.mjs
python versions/2.7.4/tests/browser-load.py
```

Для браузерного теста нужны Python Playwright и `/usr/bin/chromium`. Проверены загрузка и отмена в Chromium с имитацией API, положение кнопки, предупреждение до скачивания, заполнение полей, фильтрация связанных файлов, отказ при несовпадении документа и отсутствие записей в CRM при восстановлении. Дополнительно проверены формат JSON, обработка ошибок, привязка файла, синтаксис модулей и соответствие архива исходникам. На реальном портале новая версия не проверялась.
