# ЮЗМ · Конструктор КП 2.6.0

Один текущий расчёт на сделку, история реальных документов из Битрикс24 и единый поиск товаров с виртуальной прокруткой.

## Что изменилось

- Убраны варианты КП, создание копий и кнопка сохранения версии.
- В браузере автоматически сохраняется только один текущий черновик сделки. Нет локальной истории и массивов сохранённых версий. Предпросмотр не создаёт запись истории.
- История загружается из генератора документов CRM по ID сделки. В ней только уже созданные документы: название, дата, ссылки DOCX/PDF и обновление готовности. Включаются также документы этой сделки, созданные с другого компьютера. Для истории требуется право просмотра документов.
- Ошибка генерации не создаёт запись истории. После успешного ответа API документ появляется в списке и может быть получен заново с сервера после перезагрузки или очистки локального черновика.
- В строках расчёта больше нет select с полным каталогом. Нажатие на название товара или «Выбрать из каталога» открывает один общий диалог; он же используется для добавления и из настроек.
- В диалоге одно поле поиска по названию, вариации, названию основного товара и ID. Числовой запрос находит ID и числовые названия. `#123` или `id:123` ограничивают поиск ID товара и связанных вариаций.
- Виртуальный список создаёт в DOM только видимые строки с небольшим запасом. Поиск выполняется по заранее нормализованному индексу; каталог повторно не запрашивается при каждом вводе. Поддержаны прокрутка, стрелки, PageUp/PageDown, Home/End и добавление с клавиатуры.

## Обновление и переход со старой версии

1. Замените файлы приложения содержимым ZIP, сохранив используемый серверный обработчик. Важно загрузить новые модули `src/draft-store.js` и `src/virtual-list.js`.
2. Перезагрузите приложение с очисткой кеша (Ctrl+F5).
3. При первом запуске из прежних данных браузера переносится выбранный текущий черновик вместе с его справочниками и ручными полями. Старые локальные варианты, копии, версии и кэш документов удаляются из записей приложения; остаётся один черновик на сделку.
4. История документов заполняется данными из CRM. Старые JSON-файлы на Диске не читаются как история и не удаляются. Сформированные ранее документы в CRM не изменяются.

Текущий черновик по-прежнему локален конкретному браузеру; серверная история документов общая для доступной сотруднику сделки. Настройка папки сохранённых JSON-версий больше не используется.

## Сохранённые возможности

Поиск товаров и вариаций, цена из API или ноль с пометкой, ручная цена, покрытия и RAL, включая «Цинкогрунт + окрашивание», документы к поставке с ТРТС, самовывоз с адресом и координатами, срок исполнения числом рабочих дней или текстом «Отгрузка с СГП», условия КП, общий шаблон и индивидуальная подпись ответственного.

## Проверки

```sh
node tests/catalog.test.mjs
node tests/manager.test.mjs
node tests/execution-term.test.mjs
node tests/workflow.test.mjs
```

Пройден 31 регрессионный тест и проверка синтаксиса всех JavaScript-модулей. В Chromium с имитацией BX24 проверены:

- переход с двух локальных вариантов на выбранный текущий черновик без сохранённых версий;
- сохранение коэффициентов более старых черновиков;
- загрузка 50 004 позиций и не более 14 строк каталога в DOM, переход к концу списка с клавиатуры, поиск, добавление и замена товара через один диалог;
- получение документов из CRM, фильтрация другой сделки, создание документа, отсутствие записей истории при предпросмотре и неудачной генерации;
- повторная загрузка истории после очистки localStorage, обработка ошибок чтения документов;
- сохранение срока исполнения, условий самовывоза, контактов менеджера и цен при генерации DOCX.

Реальный портал в этой задаче не предоставлялся. На нём отдельно проверяются права сотрудника и доступность методов CRM. Виртуализация ограничивает число DOM-строк; первоначальное чтение большого каталога всё ещё зависит от пагинации, сети и лимитов REST Битрикс24.

Документация метода истории: [crm.documentgenerator.document.list](https://apidocs.bitrix24.ru/api-reference/crm/document-generator/documents/crm-document-generator-document-list.html).
