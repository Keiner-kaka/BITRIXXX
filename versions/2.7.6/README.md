# Конструктор КП ЮЗМ 2.7.6

[Скачать установочный ZIP](https://github.com/Keiner-kaka/BITRIXXX/raw/refs/heads/release/v2.7.6/dist/yuzm-kp-bitrix-2.7.6.zip)

Единственное функциональное изменение относительно 2.7.5 — несколько товаров доставки в существующем общем параметре `deliveryProductId`.

В настройках администратора, в разделе «Товары доставки», введите ID через запятую, например `101, 202, 303`, и сохраните настройки. Они едины для всех сотрудников одного установленного приложения Битрикс24. Сотрудники обновляют страницу либо открывают настройки заново. У сотрудников поле доступно только для чтения.

Пробелы вокруг ID допускаются, повторяющиеся ID учитываются один раз, некорректные и пустые элементы списка не принимаются. Один ID и пустое поле совместимы с прежней версией. Пустое поле отключает правило товаров доставки.

Стоимость всех строк указанных товаров с учётом количества входит в блок «Доставка». Эти строки остаются в КП; их надбавка К2 повторно не добавляется. Для остальных строк действует прежняя логика К2. При чтении сделки недостающие строки доставки восстанавливаются отдельно по каждому указанному товару, без замены текущих правок. Список сохраняется и восстанавливается в JSON расчёта. Права администратора, общее хранение настроек, генерация, загрузка JSON с подтверждением и привязка к документу сохранены.

Для установки замените файлы приложения содержимым ZIP и обновите страницу через Ctrl+F5. Исходники приложения находятся в корне ZIP.

Проверены расчёт с несколькими товарами, оба режима округления, отсутствие двойного К2, повторяющиеся ID, восстановление строк сделки и JSON, совместимость одного ID, общая публикация настроек и чтение сотрудником в отдельных браузерных сессиях. Проверены синтаксис модулей и соответствие ZIP исходникам. Проверки API выполнялись с имитацией; на рабочем портале версия не проверялась.
