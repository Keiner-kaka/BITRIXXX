# Конструктор КП ЮЗМ 2.7.3

Основа — предоставленный архив `yuzm-kp-bitrix-2.7.2.zip`. Сохранены его расчёт, интерфейс, генерация документов и перенос товаров; добавлено сохранение параметров расчёта на Битрикс Диск.

[Установочный ZIP](https://github.com/Keiner-kaka/BITRIXXX/raw/refs/heads/release/v2.7.3/dist/yuzm-kp-bitrix-2.7.3.zip)

## Сохранение версии

- Предпросмотр КП, ввод параметров, скачивание локального JSON и отдельная запись стоимости доставки не создают версий на Диске.
- При подтверждённой генерации документа и при подтверждённом переносе строк в сделку создаётся отдельный JSON. Генерация, включающая перенос строк, создаёт один файл.
- Файл сохраняется перед отправкой операции в CRM. Если запись JSON не подтверждена, операция останавливается с сообщением об ошибке. Если последующая операция CRM завершилась ошибкой, сохранённый файл остаётся снимком попытки, а не подтверждением успешной генерации или переноса.
- Каждая попытка получает новый UUID версии и время UTC; файл содержит ID и название сделки, компанию, идентификатор предпросмотра и вид операции (`generation` или `transfer`). Для генерации также записывается ID шаблона.
- Сохраняются только параметры использованных строк: наименования, ID товаров, базовые цены, количества, К1/К2/К3, выбранное покрытие, срок исполнения и стоимость включённых метизов. Сохраняются валюта и правило округления, при настройке — ID товара доставки. Кэш каталога, вычисленные итоги, исходные ответы API и настройки подключения в файл не включаются.

## Настройка и установка

1. Замените файлы приложения содержимым ZIP и обновите страницу с очисткой кеша. `index.html` находится в корне архива.
2. В настройках, в разделе «Версии расчёта КП», укажите положительный ID папки Битрикс Диска. Настройка сохраняется в этом браузере.
3. Приложению нужно разрешение `disk`, пользователю — право добавлять файлы в выбранную папку. Без корректного ID папки генерация и перенос строк остановятся; предпросмотр доступен.
