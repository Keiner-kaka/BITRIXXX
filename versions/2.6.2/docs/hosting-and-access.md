# Запуск и хранение данных

Приложение открывается через локальное приложение Битрикс24 или вкладку сделки. «Локальное приложение» означает установку для вашего портала, а не обязательное размещение на персональном компьютере.

Файлы приложения обслуживаются по URL обработчика. Если URL указывает на сервер или хостинг, они находятся на нём. Если веб-сервер запущен на вашем ПК, приложение доступно коллегам только при доступности этого компьютера. `localhost` и `127.0.0.1` обозначают компьютер того сотрудника, который открывает приложение, поэтому не подходят как общий адрес для коллег.

| Данные | Место хранения |
|---|---|
| Код HTML, JS, CSS | Сервер по URL обработчика |
| Расчёт и интерфейс | Браузер сотрудника |
| Один текущий черновик сделки и настройки | localStorage конкретного браузера |
| История созданных документов | CRM Битрикс24, загружается по ID сделки |
| Подписи менеджеров и справочники | Диск Битрикс24 |
| Привязки подписей и общий шаблон | Общие опции приложения в Битрикс24 |
| Товары, перенесённые в сделку | CRM Битрикс24 |

В браузере нет вариантов, копий, истории расчётов или сохранённых версий КП. Предпросмотр создаёт только временные данные в памяти. JSON можно скачать вручную как экспорт текущего расчёта; экспорт не добавляет запись в историю.

На другом компьютере текущий локальный черновик не переносится автоматически. История документов читается с сервера и доступна сотрудникам с соответствующими правами, независимо от браузера создания документа.

Права: чтение сделки, её товаров и связанного клиента; чтение каталога; чтение файлов Диска и профиля ответственного; просмотр и создание документов генератора; изменение сделки для переноса товаров. Приложению нужны области `crm`, `catalog`, `disk`, `placement`, `user_basic`.

Для истории используется `crm.documentgenerator.document.list` с фильтром `entityTypeId=2`, `entityId=ID сделки`. Если чтение документов запрещено или метод недоступен на вашем портале, показывается ошибка; локальные версии не используются как замена. При тайм-ауте проверьте также сеть, VPN, доступность портала и диагностику подключения.
