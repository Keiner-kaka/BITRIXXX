Поля сделки

Поля CRM не создаются и не удаляются. Для JSON выберите текстовое поле достаточной длины.

Расчёт и ограничения

К1 — скидка; К2 — доставка; К3 — покрытие или краска. Назначение доставки по умолчанию: К2.

JSON задаёт формулировки. DOCX-шаблон и ранее созданные документы сохраняются.

Подписи менеджеров

Используется существующая привязка к сотруднику. Файл подписи должен быть PNG или JPEG.

Результаты диагностики

Проверяются только чтение и структура данных. Права записи проверяются при соответствующем действии.
