# Подпись ответственного менеджера

Блок КП содержит должность, почту, рабочий телефон, ФИО и индивидуальное изображение подписи. Контакты берутся из профиля сотрудника, назначенного ответственным за сделку.

1. В профиле сотрудника заполните фамилию, имя, отчество, должность, почту и рабочий телефон.
2. Загрузите подпись в PNG или JPEG до 2 МБ на Диск Битрикс24. Предпочтителен PNG с прозрачным фоном. У сотрудников, создающих документы, должен быть доступ на чтение этого файла.
3. Администратором откройте приложение в сделке нужного ответственного. В блоке «Подпись менеджера» укажите ID файла на Диске и нажмите «Сохранить подпись сотрудника».
4. Скопируйте всю таблицу из [DOCX-блока подписи](../templates/manager-signature-block.docx) в свой шаблон КП и обновите шаблон в генераторе документов Битрикс24. При необходимости выберите его в настройках приложения.

Текстовые поля: `{YuzmManagerPosition}`, `{YuzmManagerName}`, `{YuzmManagerPhone}`, `{YuzmManagerEmail}`. Поле изображения `{YuzmManagerSignature}` уже находится в замещающем тексте прозрачной картинки-заполнителя в приложенном DOCX. Обычный текстовый плейсхолдер вместо картинки не заменяет изображение.

Настройка хранится в общих опциях приложения отдельно для каждого ID сотрудника. Изображения остаются на Диске; ссылки скачивания запрашиваются перед использованием и не сохраняются в черновике. Публичные ссылки на Диск приложение не создаёт.

Перед предпросмотром профиль ответственного проверяется заново. Если ответственный изменился после открытия предпросмотра, создание документа останавливается: обновите данные и заново откройте предпросмотр. Ранее созданные документы остаются в истории CRM без изменений.

При отсутствии настроенной подписи можно создать документ с контактами без изображения. Недоступность указанного файла останавливает генерацию до записи товаров. Настройку контактов можно исправить вручную; смена ответственного сбрасывает ручные данные прежнего сотрудника.
