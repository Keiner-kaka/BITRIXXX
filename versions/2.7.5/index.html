Диагностика подключения

Состояние подключения и последние запросы: методы, время, число страниц и коды ошибок. Токены, ключи и содержимое товаров не включаются.

Версии расчёта КП

Новая версия JSON сохраняется при генерации документа и при переносе строк в сделку. Укажите ID папки; приложению нужны права Диска, пользователю — право добавлять файлы в эту папку. Настройка общая для всех сотрудников этого установленного приложения; сохраняет администратор.

Расчёт

Цена единицы = (цена каталога + включённые метизы на одно изделие) × К1 × К2 × К3. Произвольные позиции входят в итог КП и передаются в товары сделки без создания товаров каталога.

Типовые формулировки КП

Тексты для новых КП и кнопок «По образцу». Для условий по метизам выберите соответствующий вариант в конструкторе. Сохранение настроек не перезаписывает текст текущего КП. Настройки общие для сотрудников этого установленного приложения; сохраняет администратор.

Связь вариантов оплаты

Одиночный вариант оплаты в конструкторе. ID — идентификатор пункта списка, а не его порядковый номер. Если в сделке выбрано несколько пунктов, выберите один вариант вручную в конструкторе. Пустой код отключает чтение. Ручные правки сохраняются.

Поле стоимости доставки

Одиночное числовое поле типа double. Сумма из блока «Доставка» записывается автоматически после сохранения товаров, перед генерацией документа. Кнопка «Доставка в поле сделки» позволяет повторить перенос отдельно. Пустой код отключает перенос.

Связь вида доставки

Соответствия по ID пунктов списка. Пустой код отключает чтение вида доставки. «Свой текст» заполняется менеджером в конструкторе; комментарий сделки автоматически не читается. Ручные правки сохраняются.

Поле адреса доставки

Поле адреса, из которого подставляются условия «Доставка силами поставщика». При изменении кода адрес подключённой сделки перечитывается. Пустой код отключает чтение адреса. Ручные условия и самовывоз сохраняются.

Товар доставки

Стоимость строки этого товара с учётом количества входит в блок «Доставка». Товар остаётся в строках КП. Надбавка К2 этой строки повторно не учитывается. Пустое поле отключает правило.

Подключение к сделке Bitrix24

Вкладка установленного приложения получает ID сделки автоматически. Для запросов REST используются права приложения.
