# Проверка прототипа

Проверки выполнены в текущем рабочем окружении на демонстрационных данных. Рабочий портал Bitrix24 не использовался.

- 34 теста Node.js: расчёт, десятичное округление, валидация справочников, REST-адаптер, пагинация, Диск, запись и повторное чтение товаров сделки, сохранение налоговых параметров.
- 13 функциональных проверок Chromium: интерфейс, товары, неоднозначные чертежи, варианты, неизменяемые версии, импорт исходного JSON, режим Excel, восстановление после перезагрузки, выгрузка, безопасный вывод текста и мобильная ширина.
- 9 функциональных проверок Chromium с имитацией BX24: контекст сделки, каталог и базовая цена, чтение справочников Диска, загрузка и проверка снимков, общая история, запись без дублей и обнаружение изменения сделки другим менеджером.

Контрольный расчёт макета: **1 948 708,34 ₽** при округлении сумм строк и **1 948 708,32 ₽** при округлении цены единицы до умножения на количество. Для записи в CRM используется округление цены единицы, поскольку товарные строки хранят именно её.

Все восемь строк исходного Excel проверены отдельным тестом: итог **3 500 090 ₽**. В этом тесте значения колонки L используются как готовые базовые стоимости; вес и ставка за килограмм не участвуют в коде калькулятора. Тест не подтверждает, что реальные цены каталога совпадают с этими значениями.

Реальное встраивание, права пользователей, CORS вашего сервера, автоматизация сделки, налоговые настройки и PHP-обработчики должны быть проверены при установке в тестовый портал. PHP в текущем окружении не установлен; эти два небольших обработчика подготовлены, но не исполнялись.

Команды:

    npm test
    npm run check

При установленном Python Playwright и Chromium дополнительно, с работающим HTTP-сервером приложения на порту 8080:

    python3 tests/browser_smoke.py
    python3 tests/browser_bitrix.py
